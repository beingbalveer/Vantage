Engineered for focus

Everything you need to review code fast.

Vantage eliminates the friction of switching between multiple IDE windows and web interfaces.

01

Split panes without window clutter

Open 1, 2, or 3 repositories or branches side by side (Mod+\). Each pane preserves its own file selection, scroll offset, and persistent terminal independently.

1 Column 2 Columns 3 Columns
frontend-web
api-gateway
02

Reviewed markers

Advance your review pointer to HEAD with r. Vantage shows the combined unreviewed delta across all commits without altering repo history.

v0.1
Marker
HEAD
Net changes since marker: +42 / −16
03

Embedded persistent PTY

Every repository gets a dedicated terminal drawer (Mod+`). Backed by portable-pty with a 256KB ring-buffer replay that keeps running services alive.

// Background watcher alive
$ cargo test --watch
✓ 48 tests passing (12ms)
04

Heuristic triage & definition peek

Automatic badges flag commits that touch secrets, update dependencies, or delete test suites. Hold Alt and click any symbol in a diff to peek its definition across your workspace.

Secrets Warning Checked for API tokens & keys
Dependencies Lockfile modified
Tests Removed Alerts if tests deleted
05

100% system Git compatibility & zero telemetry

Vantage runs entirely locally. It inherits your existing SSH keys, GPG signing configs, and hooks directly from your system Git CLI. No cloud servers, no account required.

0 KB Telemetry sent
< 30MB Idle RAM
< 50ms Cold startup
