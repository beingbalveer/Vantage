# Vantage v1 archive

This directory keeps the original Vantage v1 material for history:

- `PRODUCT_SPEC.md` and `DESIGN.md` — the Tauri + Svelte product and design specs.
- `decisions.md` and `adr/` — the v1 architecture decisions.
- `COMPARISON_GITHUB_DESKTOP.md`, `PROTOTYPE_REVIEW.md` and
  `PRODUCTION_REVIEW_2026-10-16.md` — v1 research and reviews.
- `perf.md` and `qa.md` — v1 performance and QA notes.
- `production-review-assets/` — screenshots referenced by the v1 review.

Vantage v2 is the native GPUI dashboard described in the repository
[README](../../README.md) and [architecture note](../../ARCHITECTURE.md). The v1 source
code lives in Git history; it is intentionally not part of the current working tree.
