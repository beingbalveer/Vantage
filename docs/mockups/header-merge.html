1 What collapses

Before: native macOS titlebar 28px + app header 56px = 84px. After: one shared bar, 42px, with the traffic lights inside it. The table gains 42px of height.

2 What stays put

The lights remain native controls, the window stays draggable, and double-click still zooms. The collapse button, breadcrumb and actions simply move into the same row.

3 The one caveat

42px fits natively. GPUI 0.2.2 can only move the lights inside a ~28px container; the 56px option would need a small native titlebar-container resize shim. Dragging needs a performWindowDragWithEvent shim either way.
