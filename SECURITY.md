## Reporting a Vulnerability

The Vantage team takes the security of our application and our users seriously.

If you believe you have discovered a security vulnerability in Vantage, **please do not disclose it publicly via a GitHub issue or discussion.**

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   Navigate to the **Security** tab of the [Vantage repository](https://github.com/beingbalveer/vantage/security) and click **"Report a vulnerability"** to submit a private advisory.

2. **Email**:
   If private vulnerability reporting is unavailable, please send an email with detailed reproduction steps to the project maintainer via GitHub contact.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept demonstrating how to reproduce the issue.
- The operating system, version of Vantage, and system Git version tested on.

### Response Commitment

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will keep you updated on our progress toward validating and patching the issue.
- Once a fix is verified and released, we will credit your responsible disclosure in our release notes (unless you prefer to remain anonymous).
